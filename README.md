## Fishman
- This is a 7-pedal analog guitar processor!
- It features:
- Fuzz Face
- Distortion
- Overdrive
- Phaser
- Flanger
- Delay
- Chorus
Being 100% analog, it delivers a fantastic vintage sound straight out of the 80s and 90s. When designing it, I was heavily inspired by the psychedelic sound of King Gizzard & The Lizard Wizard. Since the enclosure is shaped like a fish, I named it 'Fishman'.
